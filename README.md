# lpc0220.github.io

Pengcheng Li's technical blog on AI and AGI, served by GitHub Pages at
<https://lpc0220.github.io>.

- Posts: `_posts/YYYY-MM-DD-slug.md` (Jekyll, Minima theme).
- Images: `assets/images/<slug>/`.
- Figure sources: `_tools/<slug>/` (not published).

Local preview: `bundle install && bundle exec jekyll serve`.
